# Using Welcome Tour

This guide is for owners and operators who set up the admin tour. Every step uses the labels you see on screen.

## What you're looking at

| Screen or signal | What it tells you |
| --- | --- |
| **Welcome tour** settings | Whether the tour is on and what its steps are |
| A step | One pointer in the tour, with its description and icon |
| **Restart tour** | The option to take the tour again |

## What to do when...

| Situation | What to do |
| --- | --- |
| You want to help new admins | Turn on **Enable welcome tour** |
| A step is unclear or outdated | Edit its **Description** in the settings |
| Someone wants to retake the tour | Use **Restart tour** |
| The tour gets in the way | Users can choose **Remind me later** to snooze it |

## Settings and retention

- Keep the tour short and focused on the first few things a new admin needs.
- Update steps when your admin screens change, so the tour stays accurate.
